- **Fixed (Admin API):** enqueueing a post-meeting job against a meeting that does not exist now returns **404 Unknown meeting `<id>`** instead of 500. The insert hit the `post_meeting_jobs_meeting_id_fkey` foreign key and the raw `IntegrityError` escaped the route, so an operator's bad input read as a server fault and dumped a traceback into the logs. The repository now translates that specific foreign-key violation (SQLSTATE `23503`) into a typed error and rolls the aborted transaction back, so the session stays usable; any other integrity failure still surfaces untouched.
